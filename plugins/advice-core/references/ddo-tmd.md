# DDO / TMD — drafting notes

**Not legal advice.** Design and Distribution Obligations apply to issuers and distributors (including advisers). ASIC RG 274. ASIC has used stop orders and court penalties for TMD failures.

## What skills may do

- Check **marketing copy** and **product-research notes** against a TMD the user supplied: is the description consistent with the target market, or does it look like it would attract people outside it?
- Flag missing TMDs: `INPUT NEEDED: current TMD for [product]`.
- Record the TMD version/date the check used.

## What skills must not do

- **Coach a client through TMD gating questions** (that is distribution conduct the issuer/distributor must control).
- Decide that a client **is** or **is not** in the target market. Mark `[review]` for the adviser.
- Invent TMD content from model knowledge. If no TMD is in session, stop the TMD-alignment section.

## Check shape (for `ddo-tmd-check` and `marketing-review`)

```
PRODUCT: [name]
TMD: [sourced: file/date/version] or INPUT NEEDED
CLAIMS IN COPY / RESEARCH NOTE:
- [claim] — consistent with TMD / tension with TMD / not addressed in TMD
GATING: not performed by this tool — adviser/distributor process
REVIEWER ACTION: [what a human must confirm before publish or recommend]
```
